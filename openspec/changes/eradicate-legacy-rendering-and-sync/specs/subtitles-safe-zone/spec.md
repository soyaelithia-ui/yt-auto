# Spec: Subtitles Safe Zone (Delta)

## MODIFIED Requirements

### Requirement: Subtitle Generator Interface
Subtitles SHALL be generated by `ASSSubtitleGenerator` in `src/media/subtitles_ass.py` with strict safe-area margin compliance.

#### Scenario: ASS Header generation with safe margins
- **Given** narrative word timestamps
- **When** `ASSSubtitleGenerator` builds the subtitle descriptor
- **Then** `MarginV` SHALL be >= 240 pixels for vertical mobile UI safety.
- **And** `PlayResY` SHALL match the active canvas resolution (1920 for vertical short, 1080 for horizontal longform).
