# Proposal: SCP Narrative Scripting & High-Retention Engine

## Problem Statement
Current horror and SCP scripts generated by `src/curators/moku_horror.py` and `src/agents/script_curator.py` suffer from low Average View Duration (AVD < 45%). Root causes include passive encyclopedic exposition, boilerplate wiki intros, absence of 6-second micro-resets, and disruptive channel outros that trigger immediate swiping in Shorts.

## Proposed Solution
Upgrade the narrative curator and script generation architecture with proven retention mechanics:
1. **LaloBeRoth Formula**: Conversational, incident-driven hooks, character conflicts (Clef vs Kondraki, Incident 096-1-A), creative entity nicknames, and macabre irony.
2. **JOMOSU Formula**: Clinical-to-visceral descent, body horror sensory anchors, and Addenda twists.
3. **Dr. Bob Formula**: 3-stage experiment escalation loops (Control -> Stress -> Catastrophe) with named D-Class test subjects.
4. **Shorts Loop Engineering**: Absolute elimination of outro CTAs; enforcement of syntactic and acoustic seamless loop connectors (<60s).

## Impact Assessment
- **Performance**: Negligible CPU footprint; deterministic offline mockable fallbacks.
- **Media Pipeline**: Enhances `SceneContract` with precise 7-10s scene bounds, tension-graded Rec.709 color profiles, and kinetic subtitle markup.
- **Rollback Plan**: Fallback to canonical presets if dynamic synthesis fails; strictly backward-compatible with `INarrativeCurator`.
