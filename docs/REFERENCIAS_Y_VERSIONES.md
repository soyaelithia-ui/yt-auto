## 1. Versiones Fijadas de Componentes

| Componente | Versión Auditada | Ámbito de Uso |
|---|---|---|
| **Python** | `3.12.x` (`3.10+`) | Runtime principal del backend y pipeline. |
| **FFmpeg** | `7.0+` / `6.1+` | Motor de composición de video, filtros ASS y masterización EBU R128. |
| **SQLite** | `3.45+` | Persistencia atómica transaccional en modo Write-Ahead Logging (WAL). |
| **Node.js / npm** | `20.x LTS` | Servicios auxiliares de TypeScript y automatizaciones Playwright. |
| **Antigravity CLI (`agy`)** | `v1.1.10+` | Arnés de ejecución para sesiones Pro OAuth y agentes nativos. |
| **Telegram Bot API Server** | `aiogram/telegram-bot-api:latest` | Servidor local para transferencias de hasta 2 GB con transporte zero-copy. |
