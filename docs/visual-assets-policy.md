# Visual assets policy

> **Estado:** OFICIAL / REPOSITORIO
> **Alcance:** local video resources and text-free AI thumbnails

## Rules

1. **Video resources** are local motion assets under `assets/videos/` or `assets/loops/`, indexed by `LoopCatalogRepository`. Production uses `LoopVideoEngine` and stream-copy composition whenever geometry permits.
2. **No runtime graphics**: production must not generate frames, camera motion, HUDs, SVG/raster overlays, drawtext, drawbox, procedural shaders, or browser graphics.
3. **Clean assets**: video resources must not contain baked title cards, warning badges, CRT/HUD chrome, or finished covers. Quarantined paths and overlay folders are excluded by the asset resolver.
4. **Thumbnails** live in `assets/thumbnails/ai_bank/` when generated by the local image model. A sidecar declaration with `text_free: true` is supported; filenames that advertise text, titles, badges, logos, watermarks, or overlays are rejected.
5. **No thumbnail typography**: `ThumbnailEngine` may resize and grade a selected local image, but never prints titles, badges, watermarks, or captions. The SEO agent only returns a `thumbnail_asset_request` for the local bank.
6. **Fallbacks** are deterministic and local: clean template/scenery assets only. If no valid local asset exists, thumbnail generation fails closed; it never synthesizes noise or downloads remote imagery.
